Tower of Heaven: an unofficial engine for the original game
===========================================================

This runs Askiisoft's Tower of Heaven (2009) on a new engine. It does not
include the game: it needs your own copy of the original Windows version.

1. Put "Tower of Heaven.exe" (from the original game) in this folder,
   next to "toh".
2. Run ./toh

The first start reads the game out of the exe (it takes under a second) and
keeps it in ~/.local/share/Askiisoft/Tower of Heaven/. After that the exe
is no longer needed. Saves go to the same folder.

settings.ini (next to toh) has a few options; with no settings file the game
is exactly the original.

Controls are the original's: arrow keys to move, Up or Z to jump, Down or
X to talk and use doors, Q for the menu, W for the rulebook.

Switch 2 (homebrew): copy the zip's "switch" folder to the root of your SD
card, put "Tower of Heaven.exe" in sdmc:/switch/toh/ and start it from the
homebrew menu. The first start also puts the game's icon on the menu. Controls: stick or
D-pad to move, A or X to confirm, talk and use doors, B or Y to jump, + for
the menu, - for the rulebook, + and - together to quit.
